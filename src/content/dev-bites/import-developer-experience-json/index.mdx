<Heading tag="h2" id="context" linkLabel="Link to heading: Any project configured with JSON">Any project configured with JSON</Heading>

Any project that uses JSON for the configuration.

<Heading tag="h2" id="problem" linkLabel="Link to heading: No autocomplete in JSON files">No autocomplete in JSON files</Heading>

There is no autocomplete in your IDE for JSON files, unlike in TypeScript.

<Heading tag="h2" id="solution" linkLabel="Link to heading: Point $schema at a published schema">Point $schema at a published schema</Heading>

Use `$schema` field in your JSON file to point to the schema from the metadata file  
For instance in `package.json`:

```json
{
  "$schema": "https://json.schemastore.org/package.json",
  "name": "test-package"
}
```

When you hit cmd + space (ctrl + space for non-macos systems) it will show you all of the possible fields.  
Moreover, it provides basic validation IDE that will highlight incorrect value for the key.

I'm using schemas from [Schema Store](https://www.schemastore.org/json/) which supports many IDE and even more schemas.
