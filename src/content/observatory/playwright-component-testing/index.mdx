**Status:** Stable since [1.62](https://playwright.dev/docs/release-notes) (July 2026), on a new stories and galleries model

**Recommendation** Viable now. On `@playwright/experimental-ct-*`, you are on a frozen package - stay on 1.62 and follow the migration guide. [Vitest Browser](https://vitest.dev/guide/browser/) remains a real alternative, no longer the default answer.

<Heading tag="h2" id="overview" linkLabel="Link to heading: Overview">Overview</Heading>

- Cross-framework support (React, Vue, Svelte)
- Real browser testing environment
- Unified tooling with E2E tests (Playwright becomes a E2E standard nowadays)

<Heading tag="h2" id="known-issues-and-tradeoffs" linkLabel="Link to heading: Known Issues & Tradeoffs">Known Issues & Tradeoffs</Heading>

- **Migration required**: `@playwright/experimental-ct-react`, `-ct-react17` and `-ct-vue` are frozen at 1.62.1 and no longer updated as of [1.63](https://playwright.dev/docs/release-notes). Existing suites need the migration guide
- **You own the pipeline**: components are built and served by your own dev server - Playwright compiles nothing. More setup, but your plugins, aliases and CSS apply
- **Code coverage**: not addressed in the docs for the new model

<Heading tag="h2" id="adoption-considerations" linkLabel="Link to heading: Adoption Considerations">Adoption Considerations</Heading>

- **New Projects**: Adoptable. Framework-agnostic - anything your dev server renders, Playwright can test. Strongest fit if Playwright is already your E2E tool
- **Existing Projects**: On experimental-ct, budget for the migration. Pin 1.62 until it is done

There are also great alternatives, that allow testing components in real browser:

- [Cypress Component Testing](https://docs.cypress.io/app/component-testing/get-started)
- [Storybook Component Testing](/blog/storybook-testing-overview/)
- [Vitest Browser](https://vitest.dev/guide/browser/)
