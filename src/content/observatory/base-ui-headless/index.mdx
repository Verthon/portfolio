**Status:** Stable since v1.0.0 (December 2025), published as `@base-ui/react`

<Heading tag="h2" id="overview" linkLabel="Link to heading: Overview">Overview</Heading>

- Unstyled components library with around 35+ components available at the moment (more to come)
- From creators of successful UI libraries: Material UI, Radix, Floating UI
- Team is fully committed [full-time for the long-term](https://bsky.app/profile/vladmoroz.bsky.social/post/3lcg2iz35v22q)
- Focused on accessibility (keyboard navigation, focus management, contrast, labeling)
- Stable since [v1.0.0](https://www.npmjs.com/package/@base-ui/react) (2025-12-11). The [release timeline issue](https://github.com/mui/base-ui/issues/2485) closed on 2026-01-06
- [Public roadmap](https://github.com/orgs/mui/projects/1) on GitHub Projects
- Docs optimized for the [LLMs](https://base-ui.com/react/overview/quick-start#working-with-llms)
- MIT license
- Optimized per component imports to avoid barrel files

<Heading tag="h2" id="known-issues-and-tradeoffs" linkLabel="Link to heading: Known Issues & Tradeoffs">Known Issues & Tradeoffs</Heading>

- **React only** implementation: no first-class support yet for Vue, Svelte, or Angular
- No official MCP Server
- Missing React Compiler adoption

<Heading tag="h2" id="adoption-considerations" linkLabel="Link to heading: Adoption Considerations">Adoption Considerations</Heading>

- **New Projects**: Go for it, whenever list of components suit your needs and you are using React.
- **Existing Projects**: Most likely not needed anymore unless you planning adding new components / creating a design-system as separate package

Unstyled, a11y-focused alternatives:

- [Mantine UI Headless](https://mantine.dev/styles/unstyled/)
- [React Aria](https://react-spectrum.adobe.com/react-aria/index.html)
- [Ark UI](https://ark-ui.com/) by founders of the Chakra UI
- [Headless UI](https://headlessui.com/)
- [Aria kit](https://www.npmjs.com/package/@ariakit/react)
